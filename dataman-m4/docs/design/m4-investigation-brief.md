# M4 Investigation Brief

## Product Slice

Check an Answer with feedback and a second attempt. Story ID still needs to be confirmed from the Module 3 backlog.

## Trace to Product Work

The learner needs immediate feedback and another attempt after an incorrect answer. The design must allow one retry after the first wrong answer and reveal the correct answer after the second wrong answer.

## Initial Design Question

**Question type:** Behavior

What should happen after the learner's first and second incorrect answers, and when should the correct answer be shown?

## Why This Question Matters

The retry rules need to be clear before coding. Otherwise, the program could reveal the answer after the first wrong attempt or allow more than two attempts, requiring changes to the logic and interface.

## Planned Evidence

- Flow / state representation
- Acceptance-criteria trace

## Why This Evidence Is a Reasonable Starting Point

A flow and state representation can show the first attempt, retry, second attempt, and answer reveal. An acceptance criteria trace can check that each path follows the two-attempt rule and provides the expected feedback.
